Keyboard shortcuts

Search Ink's commands and rebind them to the keys you prefer.

The shortcut list

  • Search commands… filters by command name or category.
  • Commands are grouped by category in tables of Action, When, Keybinding and Source.
  • When says where the shortcut works: Font Loaded, Editor or Grid.
  • Source reads Default or User; your changes are highlighted.

Rebinding

  • Click a binding — it pulses “Press keys...” — then press the new combination. It saves and applies to open windows at once. Click elsewhere to cancel.
  • Right-click a binding to reset it to the default.
  • Reset All Shortcuts restores every default, without asking.
  • If another command in the same context already uses those keys, a ⚠ appears naming it. The new binding is still saved, so resolve the clash yourself.

On macOS, bindings are shown as “Ctrl+…”, and Ctrl in a binding matches either Ctrl or ⌘ — so “Ctrl+Z” is ⌘ Z.
