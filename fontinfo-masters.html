Masters

Masters are the drawn extremes of a family — Light and Black, Regular and Condensed. This tab adds, duplicates and removes them, and edits each master's metrics, zones, position in the designspace and custom parameters.

The master list

Masters are listed on the left; the default master carries a DEFAULT tag. Click a name to edit it on the right. The toolbar under the list has four buttons:

+ Add masterAsks for a name and creates an empty master at the end of the list. Every glyph gets an empty layer on it, ready to draw. The first master in a font becomes the default.
Duplicate masterAsks for a name and copies the selected master's metrics, alignment zones and custom parameters. Glyph outlines are not copied — every glyph starts with an empty layer.
− Remove masterDeletes the selected master straight away. Ink refuses if any glyph has outlines or components on that master and lists the glyphs (up to 20). The last remaining master cannot be removed.
★ Set as default masterMakes the selected master the reference for interpolation, compatibility checks and the default location of a variable font.

Fields on the right save when you leave them.

Identification

NameThe master's name, as shown in layer lists and master switchers.
VisibleWhether the master is shown.

Metrics

Each master has its own vertical metrics. Leaving a field empty unsets it. On export they seed the font-wide line metrics in hhea and OS/2 (which you can override on the Advanced tab), and the italic angle becomes post.italicAngle.

OpenType spec · hhea ↗OS/2 ↗post ↗
Ascender · DescenderTop and bottom of the design space for this master.
x-height · Cap heightLowercase and capital heights. They also position the standard alignment zones below.
Italic angleSlope of the italic, in degrees. The default master's angle is the one exported.
Slant angleSlant used for slanted (rather than true italic) designs.

Axis coordinates

OpenType spec · Font Variations overview ↗

One field per designspace axis, labelled with its tag and name — for example wght · Weight. Values are in design-space units, the units your outlines are drawn in. If the master has no stored value for an axis, the axis default is shown.

A font with no axes shows “No axes defined — add axes in the Designspace tab.” These are the same values as Master positions on the Designspace tab.

Zones

Alignment zones tell hinting where overshoots belong. In PostScript-flavoured fonts they become the BlueValues and OtherBlues of the CFF Private DICT: blue and other zones map to those, and the family kinds to FamilyBlues and FamilyOtherBlues.

OpenType spec · CFF ↗

Standard zones

Five fixed rows — Ascender, Cap-height, x-height, Baseline and Descender. Each sits at the matching metric of this master; you enter only the zone's size (overshoot). A size of 0 removes the zone. A row is disabled when its metric is not set on this master.

Custom zones

  • Each row has a Position, a Size and a Kind: blue, other, family blue or family other.
  • + Add custom zone adds a row at position 0; × removes one.

Custom parameters

Name / value pairs carried with the master, such as those imported from a .glyphs source. Values are read as JSON where possible and stored as plain text otherwise. + Add parameter adds a row; × removes one.

Good to know
  • Removing a master asks for no confirmation — but masters, zones, parameters and coordinates are all captured by Time Machine.
  • Masters cannot be reordered from this tab.
  • After adding a master, check the Compatibility tab: its glyphs will need outlines that match the default master's structure.
