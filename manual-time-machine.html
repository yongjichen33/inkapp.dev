Time Machine snapshots

Version history that lives inside your font file. Browse every snapshot, compare outlines, and roll the whole font back to any earlier point.

What a snapshot is

Every .ink project carries its own history (see the .ink file format), so the history travels with the file when you copy or share it. A snapshot records the state of the font at one moment, storing only what changed since the previous one, which keeps history compact.

Restoring is always font-wide: outlines, layers, kerning, anchors, features and Font Info go back together. You cannot restore a single glyph on its own.

When snapshots are taken

Ink writes each edit to the file as you make it, so there is no separate “Save”. A snapshot is a restore point on top of that.

  • Manually — press Ctrl S / ⌘ S, or click + Create Snapshot in the Time Machine tab and give it a name.
  • On import — the first time a font is brought into Ink.
  • Before every export.
  • On structural changes — when you create, delete or rename a glyph.
  • On a timer — every 10 minutes while there are unsaved changes.
  • Before every restore, as a safety copy.

Kerning, anchor and layer edits are included in the next snapshot. If nothing has changed, no snapshot is created.

When you press Ctrl S on an opened OTF, TTF or WOFF, Ink first asks you to save the font as an .ink project; the conversion becomes that project's first snapshot.

Opening Time Machine

Click the History (clock) icon in the title bar, or press Ctrl Shift H / ⌘ ⇧ H. Time Machine opens as a tab beside your other views. The top bar shows how many snapshots exist and how much space the history uses.

Browsing the timeline

  • Navigate with the filmstrip and the timeline scrubber. Click a frame or a node, or step with the arrow keys — ↑ / ← go back in time, ↓ / → go forward.
  • Filter by kind with the chips: Auto Save, Manual, Import, Export and Restore points, each with a count. If nothing matches, use Reset filters.
  • Read the summary. The selected snapshot lists what changed, grouped by area: Masters, Metadata, Kerning, Anchors, Features and Outlines.
  • Rename manual snapshots from the card's menu.

Comparing outlines

In the Outlines group, click N glyphs changed · view → to open Compare outlines. Search the list of changed glyphs on the left; the preview overlays the earlier shape in red and the later one in green. When a glyph changed on a non-default master, layer pills let you switch between layers.

Restoring a version

  • Choose Restore to this version and confirm.
  • Ink first creates a Pre-restore checkpoint, so a restore can always be undone by restoring to that checkpoint.
  • A progress bar blocks the app while the restore runs. It either succeeds completely or changes nothing, and it cannot be cancelled once started.
  • Open editor tabs close and reload from the restored data.

Retention and clearing history

Ink never deletes snapshots on its own, and single snapshots cannot be deleted. The only way to remove history is Clear history…, which removes all of it:

  • The dialog shows exactly how many snapshots will go, and you type clear to confirm.
  • Manual snapshots are deleted too. This cannot be undone.
  • Your current font is untouched — only the ability to go back is removed. Ink reports how much space was freed.

When history grows past 60% of the file's size, a strip suggests clearing it. You can dismiss it for the session.

What is versioned

Included
  • Outlines, components and metrics
  • Glyph names, Unicode values, color labels, export flags, production names
  • Drawing and image layers, guidelines, anchors
  • Kerning groups and per-master pairs with direction
  • Feature code, axes, instances and designspace rules
  • Masters, zones, custom parameters, Font Info and name table entries
Not included
  • App settings and preferences, which live outside the font
  • Glyph notes — on purpose, so a restore never erases a conversation
  • Font-level vendor data such as .glyphs custom parameters and UFO lib.plist
Tips
  • Change the timer in Settings → General → Auto-snapshot interval (seconds, default 600). Set it to 0 to turn automatic snapshots off.
  • A manual snapshot of a large multi-master font can take a few seconds while a “Saving…” overlay is shown.
  • The timeline currently shows up to 200 snapshots, and filters reset when you leave the tab.
