Manual

Grid view

The grid is the font at a glance: every glyph as a cell, organised by category and script on the left, with an inspector on the right for metrics, colour labels and kerning groups.

Layout

The grid tab has three parts: the sidebar on the left, the grid with its toolbar in the middle, and the Selection panel on the right. Ctrl G / ⌘ G brings the grid to the front from anywhere.

Header

The header shows the family and style, the number of glyphs and the units per em. For variable and multi-master fonts it adds variation controls:

  • A named instance menu, which reads Custom when the sliders sit between instances.
  • A slider per axis, with ticks where masters sit. Click the number beside a slider to type a value; the small × resets the axis to its default.
  • Every cell redraws at the chosen location, so you can scan the whole font at, say, Bold Condensed.

Toolbar

Left panel

Search

Search glyph… at the top of the sidebar filters by any part of a glyph name, or by glyph ID, as you type (up to 500 results). It doesn't search by Unicode value or by character.

Categories

All shows every glyph. Below it, Categories is a tree — Letter, Number, Punctuation, Symbol, Mark, Separator and Other — with sub-categories such as Uppercase, Lowercase, Smallcaps, Ligature, Decimal Digit, Fraction, Currency, Math, Arrow, Spacing and Superscript. Only categories the font uses are listed, each with its glyph count. Click one to filter the grid; click it again to return to All.

Ink decides a glyph's category by looking it up in the bundled GlyphsData by name, production name or code point; then by Unicode range; and for unencoded glyphs by name suffix — f_i is a ligature, .sc and .smcp are small caps, .numr, .dnom and .frac are fractions, names starting with _ are marks.

To override it, right-click glyphs and choose Move to Category… (or use the group icon in the Selection panel). Pick a Category and Sub-Category and Save; Clear Override goes back to the computed values.

Super sets

Scripts the font contains — Latin, Cyrillic, Greek, Arabic, Hebrew, Thai, Devanagari, Han — plus Common (script-neutral glyphs) and Unencoded. Each shows glyphs in the font / code points in the script, e.g. 1233 / 1452. Because alternates such as a.ss01 count towards the first number, read it as a guide rather than exact coverage.

Smart sets

Smart sets track how much of a published glyph list your font covers. They come from four built-in catalogues, each a section in the sidebar: Adobe, Google, GlyphsData and Unicode Blocks.

  • Click a section's + (Add Smart Set), search the catalogue, tick one or more sets and click Add. Sets you already have are marked added.
  • Each set appears with a present / total badge.
  • Right-click a set for Add Missing Glyphs — every code point you lack, in one step — or Remove Smart Set.
  • Smart sets are saved in the .ink file. They can't be renamed or edited, and a set whose catalogue entry no longer exists moves to an Other section.

Ghost cells: filling the gaps

Selecting a single super set or smart set switches the grid to a coverage view of that set, in its own order. Glyphs you have appear normally; code points you're missing appear as ghost cells — a faint reference character, its U+ code and a +.

  • Click a ghost cell's + to add that glyph immediately, named from GlyphsData or as uniXXXX.
  • Or select several ghost cells (click, Shift, Ctrl / ⌘, or Ctrl A / ⌘ A for all missing) — the panel shows N codepoints — and click Add Glyphs. Adding more than 20 asks you to confirm the list first.
  • Real glyphs and ghost cells can't be selected together.

Selecting

  • Click selects one glyph; Ctrl-click / ⌘-click adds or removes; Shift-click selects a range.
  • Ctrl A / ⌘ A selects every glyph under the current filter or search.
  • Right-clicking doesn't change the selection.

Opening glyphs

  • Double-click a cell to open it in an editor tab.
  • The pencil in the Selection panel, or Open N Glyphs from the context menu, opens all selected glyphs together in one tab — as a line you can proof in Text mode.

Context menu

Right-click a cell for Open, Move to Category…, Create composite from Anchors and Decompose, plus any commands plugins add. If the cell is part of a selection, the command applies to the whole selection.

Adding glyphs

  • Add Glyph (Ctrl Shift N / ⌘ ⇧ N) takes a character, a code point such as U+00E1, or a name, previews the result and opens the new glyph.
  • Add Glyphs… (+ Add, or Ctrl Shift G / ⌘ ⇧ G) takes a list of names. The preview marks each as a composite (base + marks), empty, existing or invalid; with Auto-create missing components on, missing bases and marks are created as empty glyphs too.
  • Smart sets and ghost cells add glyphs by code point — see above.

Right panel: Selection

The header pill counts what is selected — 1 glyph, N glyphs or N codepoints. Its four buttons:

PencilOpen the selection in one editor tab.
TrashRemove from font. The dialog lists the glyphs and where they are still used — feature code, rules and attachment lookups. Attachment lookups are updated for you; feature code and rules are not, so run Validate afterwards. Recover removed glyphs with Time Machine.
GroupMove to category…
EraserClear the selection.

Glyph

The panel describes the glyph you clicked last (Preview: name (1 of N) when several are selected): its code points (read-only here — edit them in the glyph's editor tab), a preview with the advance box and x-height and cap-height lines, its name, glyph ID and Export checkbox.

  • Click the name to rename the glyph (single selection only). Metric formulas that refer to it are rewritten.
  • Export shows a partial tick when the selection is mixed; clicking turns export on for all.

Sidebearings and width

The LSB and RSB fields sit either side of the preview, with Width (advance width) beneath. Values are for the location on the header sliders; edits go to the master at that location. Away from a master the fields are read-only.

  • With several glyphs selected, a field whose values differ shows Mixed, and an edit applies to every selected glyph.
  • LSB and RSB are disabled for glyphs without an outline. In a composite aligned automatically from its components they show auto (N) — set the width instead.

Metric formulas

Instead of a number, type a formula beginning with = to link a metric to another glyph. The result previews in grey as you type, and is applied when you press Enter or leave the field.

FormulaMeans
=HThe same metric as glyph H — H's LSB in the LSB field, H's RSB in the RSB field, H's width in Width.
=n+10 · =o*1.1Arithmetic: + - * /, parentheses such as =(H+O)/2, negative values and decimals.
=H.lsb · =H.rsb · =H.widthA specific metric of H, whichever field you are in.
=|HMirror: in the LSB field, H's right sidebearing; in the RSB field, H's left. Useful for symmetrical pairs such as b / d.
=|This glyph's own opposite side — keeps a symmetrical glyph like o centred.
=a.scGlyph names can contain letters, digits, _ and dots.
  • A linked field shows an ƒ badge; hover it to see the formula. A red ! means the formula can't be worked out right now.
  • Changes cascade. When a glyph's metrics change, every glyph whose formula depends on it is recalculated at once — change H and every =H follows.
  • On a non-default master, =H reads H on that same master.
  • Errors — an unknown glyph, a syntax error, division by zero, a mirror in Width, or a cycle such as A → B → A — turn the field red, with the reason in its tooltip.
  • To unlink a field, type a plain number.
  • A hyphen is read as minus: =a-cy means “a minus cy”.
  • Formulas round-trip through .glyphs files as metric keys. The same syntax works in the metrics table under the editor.

Colour

Thirteen swatches: No color, then Red, Orange, Brown, Yellow, Light Green, Dark Green, Light Blue, Dark Blue, Purple, Magenta, Light Gray and Dark Gray. Click one to label every selected glyph; No color clears the label. With mixed colours, no swatch is highlighted.

Kerning groups

The Left and Right fields assign the selected glyphs to kerning groups. Type a group name and press Enter; a group that doesn't exist yet is created. Empty a field to remove that side's group. A multi-selection that disagrees shows Mixed.

FieldUsed when the glyph is…Elsewhere called
Leftthe first (left) glyph of a pair — so it describes the glyph's right edgeUFO public.kern1 · Glyphs 3 kernRight
Rightthe second (right) glyph of a pair — its left edgeUFO public.kern2 · Glyphs 3 kernLeft

If you come from Glyphs, note that its labels name the edge rather than the pair side. Pairs between groups are edited in the Kerning editor and exported as GPOS class kerning.

Compatibility

For multi-master fonts with Auto compatibility check on, a Compatibility section lists the masters where the selected glyph doesn't match the default. Click a row to open the glyph on that master. See Font Info → Compatibility.

Good to know
  • View mode, sort order and cell size reset when the grid tab is reopened.
  • There is no drag-to-reorder; order comes from Sort by.
  • Removing glyphs is undone through Time Machine, not Undo.
  • Glyphs in a compiled font opened directly are read-only for metrics; save it as .ink first.
