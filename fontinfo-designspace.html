Designspace

Define a variable family's axes, its named instances, how user values map to design values, and the style labels apps show. The tab has four sub-tabs: Axes, Instances, Mapping and Labels.

Designspace appears for source projects — .ink, .ufo, .glyphs, .glyphspackage and .designspace. It is hidden for compiled OTF, TTF and WOFF files. Fields save when you leave them.

Two scales: user space and design space

USER SPACE
What people pick

The values someone choosing a style sees, such as Weight 100–900. Axis ranges and instance coordinates are in user space.

DESIGN SPACE
What you draw

The units your outlines are drawn at, such as stem widths 20–220. Master positions are in design space.

The Mapping sub-tab connects the two. Keeping them straight is the most useful habit here — mixing them is the usual cause of odd results.

How it maps to OpenType

A variable font stores its designspace in a handful of OpenType tables. Each sub-tab of this page corresponds to one of them:

In InkOpenTypeRelationship
Axesfvar axis recordsEach axis is a VariationAxisRecord: tag, name, and minimum, default and maximum in user coordinates. Hidden sets the record's HIDDEN_AXIS flag (0x0001), which asks apps not to show the axis.
Instancesfvar instance recordsIn OpenType a named instance is an InstanceRecord — a subfamily name, optional PostScript name and one user coordinate per axis. Ink also exports each active instance as its own static font.
Mappingavar segment mapsavar re-maps each axis's normalized coordinate with a piecewise-linear segment map. Ink builds it from your user → design stops and writes it only when some axis is non-linear.
LabelsSTAT axis valuesAxis value tables name positions for font menus: format 1 a single value, format 2 a value with a range, format 3 a value linked to another (style linking), format 4 a combination across axes. Older sibling is OLDER_SIBLING_FONT_ATTRIBUTE (0x0001); Elidable is ELIDABLE_AXIS_VALUE_NAME (0x0002).
Master positions · brace layersgvar / CFF2The default master becomes the font's default outlines. Every other master and brace layer becomes a set of point deltas attached to its region of the normalized designspace — gvar for TTF, CFF2 blend data for OTF.

Normalized coordinates

Inside a variable font every axis is normalized: the minimum maps to −1, the default to 0 and the maximum to +1, linearly on each side of the default. On a Weight axis of 100 / 400 / 900, a weight of 650 normalizes to (650 − 400) ÷ (900 − 400) = 0.5. avar then bends that value — so your mapping decides where 0.5 lands among the masters — and all outline variation is stored against the result.

Registered axis tags such as wght, wdth, ital, slnt and opsz have defined meanings and ranges in the Design-Variation Axis Tag Registry; tags for your own axes should use uppercase letters, like GRAD.

Axes

OpenType spec · fvar ↗Axis tag registry ↗

Axes are listed on the left with their tag and name; hidden axes carry a HIDDEN label. The toolbar has + Add axis, − Remove axis and Move up / down (which changes the axis order).

Adding an axis

The Add axis dialog offers suggested tags; clicking one fills in every field:

TagNameMin / Default / Max
wghtWeight100 / 400 / 900
wdthWidth50 / 100 / 200
italItalic0 / 0 / 1
slntSlant−90 / 0 / 0
opszOptical Size6 / 14 / 144
  • Or type your own: a Tag of exactly four letters or digits, a Name, Min / Default / Max with min ≤ default ≤ max, and optionally Hidden (not shown to end-users).
  • Typing a registered tag fills in its name for you.
  • The new axis is added at the end, and every existing master is placed at its default.

Editing an axis

NameThe axis name shown to users.
TagFour-character identifier. Renaming it updates every master coordinate, mapping, instance and label that uses it.
HiddenHidden axes are not offered to end users.
Minimum · Default · MaximumThe axis range in user space. Ink refuses a range that would leave a master or brace layer outside it, and lists what is in the way.
Master positionsEvery master's position on this axis, in design space — the same values as Axis Coordinates on the Masters tab.

Removing an axis

An unused axis is removed immediately. If instances or brace layers still use it, Ink removes nothing and lists them, so you can clear those references first.

Instances

OpenType spec · fvar instance records ↗

Named instances are the static styles of your family. + Add instance creates “Instance N” at the axis defaults straight away; − removes the selected instance and ↑ / ↓ reorder them. Inactive instances carry an INACTIVE label.

NameRequired.
PostScript name · Style nameOptional overrides for the exported names.
Style-map family · Style-map styleOptional four-style linking for this instance.
ActiveInactive instances are skipped on export.
Axis coordinatesOne value per axis in user space, limited to the axis range shown beside it.

Mapping (avar)

OpenType spec · avar ↗

Mapping tells Ink which design value each user value lands on — so a Weight of 400 can sit wherever your Regular master is actually drawn. Choose an axis from the pills, then edit the plot or the table; they stay in sync.

The plot

  • User values run left to right; design values run bottom to top.
  • A dashed line shows a straight, linear mapping for reference. Tick marks on the left edge show where each master sits in design space.
  • Drag a stop to move it. The change saves when you let go; a click without moving changes nothing.

The table

  • USER and DESIGN columns, one row per stop, sorted by user value.
  • + Add stop places a stop in the widest gap, exactly on the current curve, so the mapping doesn't change until you edit it. × removes a stop.
  • Stops at the axis minimum and maximum can't be removed, and their user value is locked.

Rules

The mapping must keep rising, and each user value can appear only once. An edit that breaks this is refused with an explanation, and the plot and table go back to the stored mapping. An axis with no stops maps linearly; Ink writes an avar table on export when any axis is non-linear.

Labels (STAT)

OpenType spec · STAT ↗

Style labels let apps name positions on each axis — “Bold” at 700, “Condensed” at 75. Pick an axis from the pills.

NameThe label, e.g. “Bold”.
ValueThe axis value it names.
RangeOptional min and max the label covers.
LinkedOptional linked value — for example Regular 400 linked to Bold 700 for style linking.
FlagsOlder sibling and Elidable (left out of combined names, like “Regular”).

+ Add label adds one at the axis default. Below the table, the collapsible Multi-axis labels section names a combination of values across several axes, each with a name, flags and one value per axis.

Related in the glyph editor

  • Brace layers — in the editor's VAR mode, move the axis sliders or the point on the plot and click Add brace layer here to draw one glyph at an intermediate location. Or use + → Brace {} in the Layers panel.
  • Exporting — File → Export → Export Variable Font… writes OTF (CFF2) or TTF (gvar). Export as OTF / TTF… exports a single master or instance. Both are refused while any glyph has a compatibility blocker.
Good to know
  • Removing an instance or label asks for no confirmation; Time Machine captures axes, instances, mappings and labels.
  • avar version 2, designspace rules and <variable-font> descriptors are imported and kept, but cannot be edited here yet.
