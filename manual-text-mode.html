Manual · Glyph editor

Text mode

Text mode turns the glyph editor into a proofing line. Type a string, see it laid out with your kerning and OpenType shaping, and edit any glyph in it without leaving the words around it.

Starting and stopping

Getting text on the canvas

  • Every editor tab draws its glyphs as a line of text, even outside text mode — a tab opened for one glyph is a line of one.
  • Select several glyphs in the grid and choose Open N Glyphs (right-click) or Edit selected glyphs to open them as one line.
  • Ctrl T / ⌘ T opens an empty editor tab to type into.

Turning text mode on

Click the Text Mode button (the T) in the editor toolbar. The caret lands to the right of the glyph you were editing, or at the start of an empty line. If the Hand or Measure tool was active, Ink switches to Select.

Leaving text mode

Each of these hands editing to the glyph just left of the caret:

  • Esc switches to the Select tool on that glyph. (If a menu or popover is open, the first Esc closes it.)
  • Clicking an editing tool — Select, Draw, Pencil, Shape, Knife — switches to that tool.
  • Clicking Text Mode again keeps the current tool.
  • Double-clicking a glyph edits that glyph with the Select tool.

While the caret is live, tool letters such as S and D type letters, and Space types a space rather than panning.

Typing and editing

  • Each typed character is matched to a glyph by its Unicode value. A character the font has no glyph for becomes a blank placeholder half an em wide.
  • Enter starts a new line. Backspace deletes to the left and joins lines at a line start; Delete deletes to the right.
  • With a selection, typing, Enter, Backspace, Delete and paste replace it.
  • Removing glyphs from the line never removes them from the font — the line is only a viewing surface. It belongs to the tab and is kept until the tab closes.
  • Input methods for Chinese, Japanese, Korean and other scripts work: Ink waits for the composition to finish, then inserts the whole phrase, and the candidate window follows the caret.

Caret and selection

  • Click places the caret; drag, Shift-click or Shift + arrow keys select. Ctrl A / ⌘ A selects the whole run.
  • ← → move one glyph and wrap between lines. In right-to-left text, → always moves towards the right edge of the screen.
  • ↑ ↓ move to the same character position on the neighbouring line.
  • Ligatures with anchors named caret_1, caret_2 … let the caret stop inside them; without those anchors a ligature — like a base letter with attached marks — is treated as one unit.
  • The view scrolls to keep the caret visible; Ctrl 0 / ⌘ 0 fits the whole run.

Editing glyphs in context

  • Double-click a glyph — or leave text mode — to edit it with the normal tools while the rest of the line stays visible. With text mode off, double-click another glyph in the line to switch to it.
  • In a shaped line you edit the glyph you see — an Arabic medial form or a ligature — not the character you typed.
  • Edits save to the font immediately, and every copy of that glyph in the line and in other tabs updates.

Shaping

Ink shapes each line with HarfRust, the HarfBuzz project's Rust port, so text behaves as it will in apps. Behind the scenes Ink compiles a temporary static font from your default master and shapes against it.

When it updates

  • A line is reshaped shortly after you stop typing.
  • Changes to the glyph set, Unicode values, advance widths, kerning, anchors, feature code or designspace rebuild the temporary font first, so the line may briefly appear unshaped before it snaps into place. Outline edits never trigger a rebuild.

The shaper applies the standard default features — the same set HarfBuzz uses — and offers no switches:

Script, direction and language

  • Direction comes from the text-direction button, never from the text itself.
  • The script is taken from the first letter of each line, and each line is shaped on its own.
  • No language is set, so the default language system is used.

Positioning

Substitutions and mark and cursive attachment come from the shaper. Advance widths and kerning come from Ink's own data — the active master's for glyphs you typed, the default master's for substituted glyphs such as ligatures — so what you see always reflects your latest kerning.

Glyphs without a Unicode value

A glyph inserted by name (see Clipboard) appears exactly as placed and isn't shaped with its neighbours; the text on each side is shaped separately. Ink's kerning still applies to it.

When shaping fails

If the temporary font can't be built — usually because the feature code has errors — a warning-triangle button appears next to the text-direction button and the line renders unshaped. Check Font Info → Features and press Validate.

Text direction

  • While text mode is on, a Text direction button (pilcrow icon) sits next to Text Mode. It is highlighted for right-to-left.
  • Direction is set per tab, starts left-to-right, and isn't saved.
  • It decides which kerning set is read and written, the direction the shaper uses, and the column order in the metrics table and preview.
  • A right-to-left line simply runs right to left — there is no bidirectional reordering, so digits and Latin inside an Arabic line are reversed too. Use a separate tab for mixed-direction proofs.

Kerning while you type

  • The line shows your kerning for the active master and the tab's direction, and refreshes whenever kerning changes anywhere in Ink.
  • The toolbar's kern button opens the kerning panel. Context · cursor shows the pair at the caret; Context · glyph shows the left and right pairs of the glyph you are editing.
  • A value from a glyph-to-glyph pair is edited directly. A value that comes from a class pair shows the @class names and a padlock; click the padlock to unlock it and edit the class value.

The full kerning workflow is in the Kerning editor manual.

Metrics table

Turn it on with View → Show Metrics Table or Settings → Editor → Metrics Table. It sits under the preview, one column per glyph of the caret's line in on-screen order, and appears when the active layer is a master.

HeaderThe character, or the glyph name when it has no Unicode value.
LSBMoves the outline sideways, keeping the right sidebearing.
RSBChanges the advance width.
AWThe advance width.
KERNFrom two glyphs on, the pair between neighbouring columns. It edits an existing glyph pair, otherwise the pair between the glyphs' kerning classes.
  • Type a formula such as =h-1 to link a value to another glyph's metric.
  • In a shaped line, the columns follow the shaped glyphs — you kern the forms that actually appear.
  • All values are for the active master.

Preview panel

  • The toolbar's eye button shows or hides the preview strip under the canvas. Drag its top edge to resize it (80–500 px).
  • It shows the caret's whole line with the same shaping, kerning and direction as the canvas — even after you leave text mode.
  • Glyphs are sized from the font's ascender-to-descender height, so they keep their true proportions.
  • Black on white / White on black inverts it. For hinted compiled fonts, Show hinting preview renders hinted glyphs at a pixels-per-em size from 8 to 72.

Masters and variations

The active master is the edited glyph's layer, chosen in the inspector's Layers section. Switching masters updates that glyph's outline, advance and guides in the line, and switches the kerning and metrics shown. Mark positions and the advances of substituted glyphs always come from the default master.

Line length

Settings → Editor → Text line length sets how many glyphs fit on a line before it wraps (5–200, default 50). Wrapping counts glyphs, not width, and a wrap becomes a real line break.

Clipboard

  • Ctrl C / ⌘ C copies the selection as plain text; Ctrl X / ⌘ X cuts; Ctrl V / ⌘ V pastes text as if you had typed it.
  • Glyphs with a Unicode value are copied as their character. Glyphs without one are copied as /glyphname followed by a space — the convention Glyphs uses — and the slash itself as /slash.
  • Pasting /name inserts that glyph. A name the font doesn't have becomes a placeholder that keeps the name. Typing /name key by key types a slash and letters instead — paste it.
  • Pasting into an empty line sets the tab's direction from the pasted letters: Hebrew and Arabic make it right-to-left.

On macOS, Copy, Cut, Paste and Select All work through the standard keyboard shortcuts; choosing Edit → Copy from the menu bar with the mouse doesn't copy a glyph run.

Current limitations
  • Undo and redo don't apply to typed text while the caret is live. Outline edits made after leaving text mode undo normally.
  • No Home / End, word-by-word movement, or double- and triple-click selection.
  • Optional features (stylistic sets, small caps …) and language-specific forms can't be previewed yet.
  • A line mixing scripts is shaped as one script; there is no vertical text.
  • Characters missing from the font appear as blank gaps without a warning.
