Export

Default parameters for compiled fonts: curve conversion for TrueType, and the autohinters Ink runs when you tick Apply autohinting in an export dialog. Changes apply to your next export.

Autohinter readiness

Autohinting runs through Ink's optional Python environment. The box at the top of the page checks it for each hinter:

StatusMeaning
Ready ✓The hinter is installed and working — TTF (ttfautohint) or OTF (otfautohint).
Install ttfautohint-py · Install afdkoThe package is missing; click to install it into the default Python version.
No Python environmentNo Python is installed yet. Open Settings → Python takes you there.
Checking…Ink is testing the environment.

If you export with autohinting on and a package is missing, the export dialog offers to install it. Without Python, the font still exports — unhinted.

Curve conversion

TTF fonts store outlines in the glyf table as quadratic curves, while OTF fonts keep cubic curves in CFF (or CFF2 for variable fonts). One tolerance governs every conversion between the two, in both directions: exporting cubic outlines to TTF, and the Glyph → Path → Convert to Quadratic and Convert to Cubic commands.

The tolerance is measured per 1000 em and scaled to the font: the default 1.0 allows a deviation of 1 unit on a 1000-UPM font and 2.048 units on a 2048-UPM font — in line with the tolerance fontmake uses, so quadratic outlines it produced convert back to clean cubics.

OpenType spec · glyf ↗CFF ↗CFF2 ↗
SettingWhat it doesDefault
Curve conversion toleranceThe maximum distance a converted curve may stray from the original, in units per 1000 em (0.01–10). Ink scales it to each font's units per em, so the same setting behaves alike on a 1000-UPM and a 2048-UPM font. Used for TrueType export and for Convert to Cubic / Quadratic. Lower is more accurate but produces more points — and, in a TTF, a larger file.1.0

Good to know
  • Readiness is checked against your default Python version. See Python.
  • PostScript hinting zones and stems for a font are set in Font Info → Advanced → PostScript; alignment zones per master in Masters.
