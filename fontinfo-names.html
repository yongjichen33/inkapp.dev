Manual · Font Info

Names

The name table is where a font tells apps what it is called. This tab shows the names Ink generates from your Font Info, and lets you add explicit records — other languages, Mac records, or anything the generated set doesn't cover.

OpenType spec · name ↗

Two kinds of name

Derived

Generated from typed fields such as Family Name and Copyright. Editing one here writes back to the field the exporter reads.

Name table entries

Explicit records you add. An entry takes precedence over the generated record with the same name ID, platform, encoding and language.

Derived names

A table of ID, Lang, String and Source. Every derived record is written for Windows / Unicode BMP / English (United States). Only names with a value are listed.

Editing a derived name

Click a string, edit it and leave the field. Where the edit goes:

  1. If an entry already overrides that row, the entry is updated.
  2. ID 6 writes the PostScript font name.
  3. ID 4 creates or updates an entry for the full name — it never changes your family or style.
  4. Every other row writes its Font Info field. For IDs 8, 9, 11 and 12 that is the OpenType-specific field, which from then on takes precedence over the General tab's Designer and Manufacturer fields.

Clearing a string unsets the field. When an entry overrides a row, its Source column reads entry (overrides …); removing the entry falls back to the named field.

Name table entries

A table of Name ID, Platform, Encoding, Language and Value. Each row has an edit (pencil) button and a × that asks “Remove this name table entry?” — the generated record for that tuple ships instead.

Adding or editing an entry

+ Add entry opens the dialog with Windows / Unicode BMP / English (United States) and the first free name ID from 16 upward.

Name ID0 Copyright through 25 Variations PostScript Name Prefix, or Other… for any number.
PlatformUnicode (0), Macintosh (1) or Windows (3). Changing it resets encoding and language to that platform's defaults.
EncodingThe encodings of the chosen platform — e.g. Windows Unicode BMP, Mac Roman — or Other….
LanguageA filterable list of 205 Windows and 119 Mac languages, or Other….
ValueThe string.
  • “Other…” fields accept a number in decimal (1033) or hex (0x0409), from 0 to 65535. The name table specification lists every platform, encoding and language ID.
  • Two entries cannot share the same name ID, platform, encoding and language.
  • Name IDs 26–255 are reserved for future standard names; Ink warns but lets you continue. Font-specific names start at 256.

How names are exported

  • Generated records are written for Windows (3, 1, 0x0409) only. An entry with the same four values replaces the generated one; any other entry is added alongside.
  • An entry with an empty value is skipped, so the generated record ships.
  • Mac records appear in an exported font only if you add them as entries or they came from an imported font.
  • When a font is imported, names at the Windows English tuple are folded back into their Font Info fields; everything else stays an entry.
Good to know

Name records are captured by Time Machine along with the rest of Font Info.
