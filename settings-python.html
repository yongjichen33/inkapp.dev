Python

Ink installs and manages its own Python for scripts, plugins and autohinting — separate from any Python already on your computer. This page installs versions and the packages inside them.

Installing a Python version

  • Available lists versions you can install: 3.13 (Latest), 3.12 (Recommended) and 3.11. Show all versions adds 3.10 and 3.9.
  • Click Install. The first time, Ink downloads its toolchain (“Setting up Python toolchain…”), then the interpreter. A banner shows progress and has a Cancel button; other installs wait until it finishes.
  • Each version gets its own scripting environment, created straight away. Ink then installs, where it can: the ink module scripts and plugins use, plus ttfautohint-py and afdko for autohinting. afdko is large and needs a network connection.
  • If those packages can't be installed — offline, for example — the environment still works, and Settings → Export offers to install the hinters later.

Installed versions

Each installed version shows its size on disk and either a Default badge or a Set Default button.

  • The default version is the one scripts, plugins and autohinting use. The first version you install becomes the default.
  • Click a version to expand it: its packages appear, along with Uninstall Python X.
  • Uninstalling asks “Remove Python X and all packages?”. If you remove the default, the newest remaining version takes over.

Packages

An expanded version lists the packages in its environment.

Installed packagesName and version. ink carries a Built-in badge and is kept up to date by Ink. Other packages show their newer version when one exists, with Update and Remove buttons. Remove doesn't ask first.
Install packageType a name from PyPI — “fonttools”, “numpy” — and press Install or Enter.
Suggested for font developmentOne-click chips for fonttools, ufoLib2, afdko, glyphsLib, defcon, fontmake, cu2qu and booleanOperations. Hover a chip for a description.

Running scripts

  • Choose Run Script… — in the Help menu on Windows, or the Ink menu on macOS — or run “Open Script Console” from the command palette.
  • The Script Console tab has a list of recent scripts, Browse…, ▶ Run and Clear, and a Cancel button while a script runs.
  • Scripts use the default version's environment, with import ink available. See the Python reference.

Where it lives

Everything sits in Ink's app folder — %APPDATA%\com.intaglio.ink\ on Windows, ~/Library/Application Support/com.intaglio.ink/ on macOS — under python/ for interpreters and environments/ for the scripting environments.

Trust

Scripts and plugin Python run with your user account's full access to files and the network. Only run scripts and install plugins you trust.
