Manual · Settings

General

Settings holds preferences for Ink itself — not for any one font. The General section covers appearance, Time Machine, undo, updates and compatibility checking.

Opening Settings

  • Windows: File → Settings… or Ctrl ,
  • macOS: Ink → Settings… or ⌘ ,
  • Or run “Settings…” from the command palette (Ctrl Shift P).

Settings opens in its own window, always on General. If it is already open, it comes to the front. The sidebar has two groups: Settings — General, Editor, Export and Keyboard Shortcuts — and Extensions — Python and Plugins.

How changes are saved

  • There is no OK or Apply button: every change saves immediately and reaches all open windows.
  • Number fields save when you leave them or press Enter.
  • General, Editor and Export each have a Reset to Defaults button that resets that section only, without asking.

Where settings live

Settings are stored in settings.json — %APPDATA%\com.intaglio.ink\ on Windows, ~/Library/Application Support/com.intaglio.ink/ on macOS. They are never written into a font file and are not part of Time Machine history. Out-of-range values are corrected when Ink starts; a file that can't be read is replaced with the defaults.
