Reference

OpenType references

The OpenType tables Ink writes when you export a font, what each one is for, and where in Ink you control it. Every table name links to its chapter of the OpenType specification on Microsoft Learn.

Naming and identification

TableWhat it holdsIn Ink
nameEvery human-readable string: family, style, full and PostScript names, copyright, licence, axis and instance names.Font Info → Names, General
OS/2Weight and width class, vendor ID, style flags, PANOSE, Unicode and code-page ranges, embedding rights, typo and Windows metrics.General, Advanced → OS/2
headUnits per em, style bits, rasterizer flags, dates.General, Advanced → head
postItalic angle, underline, fixed pitch, glyph names (format 2) or none (format 3).Advanced → PostScript, Masters

Metrics

TableWhat it holdsIn Ink
hhea · hmtxHorizontal line metrics and caret slope; every glyph's advance width and left sidebearing.Masters, Advanced → hhea, glyph metrics in the editor
vhea · vmtxVertical-layout metrics, exported when needed.Advanced → vhea

Outlines and characters

TableWhat it holdsIn Ink
glyfQuadratic TrueType outlines (TTF).Settings → Export (curve conversion)
CFF · CFF2Cubic PostScript outlines and hinting values (OTF); CFF2 for variable fonts.Advanced → PostScript, Masters → Zones
cmapMaps Unicode code points to glyphs.Each glyph's Unicode values in the grid inspector
gaspGrid-fitting and smoothing per pixel size.Advanced → gasp

Layout

TableWhat it holdsIn Ink
GSUBGlyph substitution: ligatures, alternates, small caps, contextual forms.Font Info → Features
GPOSGlyph positioning: kerning, mark attachment, cursive attachment.Kerning editor, anchors in the editor, Features
GDEFGlyph classes (base, ligature, mark), mark sets, ligature carets.Glyph categories; generated on export
kernLegacy kerning table, superseded by GPOS.Read from imported fonts

Registries: feature tags, script tags and language system tags. Feature code is written in the OpenType Feature File syntax (Adobe).
