Python reference

The ink module gives Python scripts typed access to an .ink project: fonts, glyphs, layers, masters and kerning. It is a native extension built on the same Rust ink-api crate the app uses, and comes preinstalled in Ink's scripting environment.

import ink font = ink.current_font() print(font.family_name, font.style_name, font.units_per_em) for glyph in ink.selected_glyphs() or font.glyphs: print(glyph.name, len(glyph.contours), glyph.width)

Conventions

  • Contours, points, components, anchors and guidelines are plain dicts, not classes.
  • A contour is {"points": [{"x": float, "y": float, "point_type": "oncurve" | "offcurve" | "smooth"}], "closed": bool}.
  • Glyph-level properties act on the default master; use Layer or Master.glyph_layer() for other masters.
  • Coordinates written through the API are rounded to 3 decimals.
  • Failures raise RuntimeError with a message beginning Not found:, Database error:, Invalid data: or IO error:; an unknown point_type raises ValueError.

Example: fit sidebearings

A complete script that asks for a value, shifts each selected glyph's outline so both sidebearings match it, and reports contour counts.

import ink font = ink.current_font() opts = ink.ui.form("Fit sidebearings", fields=[ ink.ui.field("sb", "number", label="Sidebearing", default=50, min=0, max=500), ]) if font is None or opts is None: raise SystemExit sb = opts["sb"] glyphs = ink.selected_glyphs() or font.glyphs for i, g in enumerate(glyphs): ink.ui.progress(f"Fitting {g.name}…", percent=i * 100 // len(glyphs)) contours = g.contours xs = [p["x"] for c in contours for p in c["points"]] if not xs or g.components: # skip empty and composite glyphs continue left, right = min(xs), max(xs) # control-point bounds for c in contours: for p in c["points"]: p["x"] += sb - left g.contours = contours g.width = (right - left) + 2 * sb print(f"{g.name}: {len(contours)} contours") ink.ui.progress() font.save()
Good to know
  • In projects converted from compiled fonts, kerning and anchor writes stay read-only unless Ink was able to turn that data back into native kerning and anchors.
  • Image layers are not included in Glyph.layers; use get_image_layer().
  • Axes and font-level guidelines are not exposed to Python yet.
