Kerning editor

A dedicated window for viewing, adding and editing kerning pairs and classes for each master — as a sortable list or a class-by-class matrix, with full left-to-right and right-to-left support.

Opening the editor

Press Ctrl Shift K / ⌘ ⇧ K. The Kerning Editor opens as its own window for the active font (or comes to the front if already open) and closes when you close that font.

Masters and views

  • Master — choose which master's values you are editing. It starts on the default master; every master stores its own kerning values.
  • List / Matrix — switch between the two views in the top-right corner.
  • In fonts converted from OTF or TTF, a note may say that some kerning rules from the original font are preserved but cannot be edited, with the reason. Those rules stay in the font as feature code.

List view

Finding pairs

  • Filter glyph or class… searches both sides.
  • Kind chips: All, Pair (glyph–glyph), Group (class–class), Exception (glyph–class or class–glyph) and Fallback (pairs not tied to a particular master).
  • non-zero only hides pairs whose value is 0; the direction menu filters to LTR, RTL or vertical.
  • Click the First, Second or Kern column header to sort; click again to reverse.

Editing

  • Click a value, type a number, then Enter to commit or Esc to cancel. Clicking away also commits.
  • The chevron at the end of a row opens a drawer with each glyph's LSB, RSB and advance width and a preview of the pair.
  • Check rows and use Delete (n) to remove them after a confirmation.

Adding pairs and classes

  • + Add — choose the first and second side (a glyph or a class), a value and a direction. If the list is filtered to LTR or RTL, that direction is preselected.
  • + New Class — choose Left (first) or Right (second), type a name (the @ is added for you, e.g. @kern.left_a) and pick members from a filterable glyph list.
  • From the grid — every glyph's left and right kerning groups can also be set in the grid inspector. When a multi-glyph selection disagrees, the field shows “Mixed”.

Matrix view

A grid of first classes against second classes, with a count such as “12 × 30 classes”. Turn on Hide empty rows/columns to declutter. Click a cell to select it and double-click to edit its value.

A cell where the same class pair exists in both LTR and RTL is marked mixed directions and cannot be edited in the matrix; its tooltip shows both values. Edit those pairs in the list view.

Right-to-left kerning

  • Direction belongs to each pair, not to the font, so one font can mix Arabic and Latin, and the same pair can carry separate LTR and RTL values.
  • Pair sides are logical — first and second — not left and right. In RTL text the first glyph appears on the right.
  • A new pair gets the direction you choose in the Add dialog or with the LTR / RTL toggle in text mode. Ink never guesses it from the glyphs.
  • Vertical kerning from imported fonts is shown read-only.

Kerning while you type

You do not have to leave the glyph editor to kern. In text mode, the kerning panel shows the pair at the cursor; when the value comes from classes it shows their @class names.

  • A value from a glyph-to-glyph pair is edited directly. A value that comes from a class pair is locked; click the padlock to unlock it and edit the class value.
  • In the metrics table's KERN row, an edit changes an existing glyph pair, or otherwise the pair between the glyphs' kerning classes. See Text mode.
  • View → Show Metrics Table lists LSB, RSB, width and kern for every glyph on the current line, in on-screen order (reversed for RTL).

How kerning is exported

In compiled fonts, kerning is a GPOS pair-adjustment lookup (lookup type 2): glyph pairs use format 1, class pairs format 2. The legacy kern table is not needed by modern apps.

OpenType spec · GPOS ↗kern · dist feature tags ↗legacy kern table ↗
FormatBehaviour
OTF / TTFInk builds the kern feature (and dist for Indic-style scripts) from your kerning on every export. You never write kern feature code by hand.
UFOWritten to groups.plist and kerning.plist. If a pair exists in both directions the LTR value is written, with a warning; vertical pairs are left out.
.glyphsLTR, RTL and vertical kerning are all kept.
Good to know
  • Fonts opened directly as OTF or TTF are read-only. Save them as an .ink project to edit kerning.
  • Kerning edits are captured by Time Machine at the next snapshot.
