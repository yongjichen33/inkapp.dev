Manual · Settings

Editor

How the glyph editor looks and behaves: zoom, point sizes, rounding, snapping, and what new windows show by default.

Zoom and points

SettingWhat it doesDefault
Zoom minThe furthest you can zoom out (0.01–1).0.02
Zoom maxThe furthest you can zoom in (2–200).50
Zoom stepScroll-wheel zoom multiplier (1.01–2).1.1
On-curve point radiusSize of on-curve points, in pixels (1–20).5 px
Off-curve point sizeSize of handles, in pixels (1–20).7 px
Hit detection radiusHow close a click must be to select a point (2–30 px).8 px
Pencil fit toleranceHow closely the pencil traces your stroke. Lower keeps more nodes; higher gives smoother curves (0.1–10).1.5

Coordinates

SettingWhat it doesDefault
Round when editingRounds coordinates to the font's grid step as you draw — whole units on the default grid. Turn it off to draw in fractional space; coordinates are still trimmed to the precision below. Applies whether or not the grid is shown.On
Coordinate precisionDecimal places kept on coordinates, 0–3. 0 keeps whole units. A font with a finer grid keeps the decimals its grid needs, and a font whose grid spacing is 0 keeps full precision.3 dp
Default advance widthWidth of new glyphs at 1000 units per em (0–2000), scaled for other UPMs. Marks start at 0 and spaces at UPM ÷ 4.500

Each font's rounding step is set by Grid spacing and Grid subdivision in Font Info → General.

Defaults for new windows

These set what a newly opened font window starts with. Each open window keeps its own state, changed from the View menu — changing a default here doesn't flip windows that are already open.

SettingWhat it doesDefault
Show pixel gridThe grid behind the outline (View → Show Grid, Ctrl ').On
Show alignment zonesShaded overshoot zones (View → Show Zones).On
Show Glyph ReferenceThe tracing reference font behind the outline.Off
Show RulersRulers along the canvas edges.On
Snap to metrics & zonesDragged points snap to metric lines and alignment zones.On
Snap to nodesDragged points align with, and land on, other nodes.On
Snap to handlesOff-curve handles count as snap targets too.On

Round when editing (above) follows the same rule; toggle it in an open window with Ctrl Shift ' / ⌘ ⇧ '.

Text mode

See the Text mode manual for how these are used.

SettingWhat it doesDefault
Metrics TableShows the table under the preview with LSB, RSB, advance width and, from two glyphs on, kerning for the line the cursor is on — one editable column per glyph. Same as View → Show Metrics Table; applies everywhere at once.On
Text line lengthGlyphs per line before text wraps (5–200). Raising it doesn't rejoin lines already wrapped; lowering it applies from your next edit.50
Good to know
  • The Fit Curve presets (Ctrl Alt 1–8) take their tension range from the Fit Curve panel in the editor, not from this page — but Reset to Defaults here resets that range too.
  • Zoom and point-size changes apply to open windows straight away.
