Manual · Font Info

Advanced

Expert overrides for individual OpenType tables. Ink computes sensible values for all of these on export; fill a field only when you need to depart from the computed default.

Derived values and overrides

  • An empty field shows the value Ink will derive as a grey placeholder. Leave it empty and the field keeps following its source.
  • Click the Recalculate icon inside a field to write the derived value in. From then on it is a fixed override and no longer follows its source.
  • Empty the field again to return it to automatic.
  • The groups below are collapsed when the tab opens; click a heading to expand it.

For a compiled font opened directly, a banner warns that changes aren't saved to disk — export an OTF or TTF to write them.

OS/2 (advanced)

OpenType spec · OS/2 ↗
Selection flagsfsSelection checkboxes: Underscore, Negative, Outlined, Strikeout, Use typo metrics, WWS and Oblique. Italic, Bold and Regular are shown read-only — they come from the Style Name on the General tab.
PANOSEThe 10-digit visual classification. Choose a family type first (Latin Text, Latin Hand Written, Latin Decorative or Latin Symbol); the nine remaining digits then appear with labelled choices such as Serif style, Weight and Proportion. Changing the family type resets them.
Family classsFamilyClass — an IBM class such as Oldstyle Serifs or Sans Serif, plus a subclass where one applies.

Code page rangesulCodePageRange1–2, edited the same way, grouped into Windows and OEM / MS-DOS code pages.

OS/2 typo line gapExtra line spacing.
OS/2 win ascent · win descentRead-only. Measured at export from the tallest and lowest outlines in the default master; “—” when there is nothing to measure.
Embedding permissionsfsType: Installable, Restricted license, Preview & print, or Editable embedding, plus No subsetting and Bitmap embedding only.
Subscript · SuperscriptX and Y size and offset for each.
Strikeout size · positionThickness and height of the strikeout line.

If an imported flag value doesn't look like a valid bit list, Ink warns that editing it will replace it.

gasp

OpenType spec · gasp ↗

Grid-fitting and anti-aliasing behaviour per pixel size. With no rows, no gasp table is exported.

  • Add range adds a row with a Max PPEM and four switches: Grid-fit, Grayscale, Symmetric grid-fit and Symmetric smoothing.
  • Rows are sorted by size when saved.
  • Ink warns if the last row doesn't reach 65535 (sizes above it fall back to the rasterizer's defaults) or if two rows share a size.

vhea (vertical layout)

OpenType spec · vhea ↗vmtx ↗
Vertical metricsAuto, On or Off. Auto exports vhea / vmtx when vhea fields are set or any glyph has vertical metrics. A status line says whether the tables will be exported and why. Off keeps the stored values but doesn't export them.
vhea ascender · descender · line gapDefault to half the em above and below, and 0.
Caret slope rise · run · offsetDefault 0, 1 and 0.

Setting vhea fields can turn Auto export on, so these fields have no Recalculate.

PostScript

OpenType spec · post ↗CFF ↗name (ID 6) ↗

The post table carries the underline values, fixed-pitch flag and glyph-name format. The hinting zones, stems and width defaults belong to the CFF table's Private DICT, used by OTF (PostScript-flavoured) fonts.

post table formatAuto (3 for OTF, 2 for TTF), 2 — with glyph names, or 3 — no glyph names. Format 3 drops glyph names; in a TTF they can't be recovered.
PS Font NameThe PostScript name (name ID 6). Defaults to Family-Style, limited to ASCII letters, digits and dots.
PS Full NameDefaults to “Family Style”.
PS Slant AngleDefaults to the italic angle.
PS Weight NameDefaults from the weight class, e.g. Bold for 700.

Blue fuzz · Blue shift · Blue scale · Force boldFurther PostScript hinting parameters.

WOFF metadata

W3C · WOFF extended metadata ↗

WOFF major and minor version, a metadata unique ID, and JSON fields for Vendor, Credits, Description, License, Copyright, Trademark, Licensee and Extensions.

Macintosh legacy

FOND family ID and FOND name, for classic Mac font suitcases.

Raw vendor JSON

Keys Ink doesn't recognise, kept from the imported source and written back unchanged on export. It must be a JSON object; anything else is refused when you leave the field, and nothing is saved until the error is fixed.

Good to know
  • Leaving these fields empty is the safest choice — Ink's derived values follow your metrics as they change.
  • Advanced values are captured by Time Machine with the rest of Font Info.
