Plugins

Turn installed plugins on and off, and load a plugin you are developing from a local server.

Installing a plugin

  1. Copy the plugin's folder — it contains a plugin.json and its HTML — into the plugins folder:
    • Windows: %APPDATA%\com.intaglio.ink\plugins\
    • macOS: ~/Library/Application Support/com.intaglio.ink/plugins/
  2. In Settings → Plugins, click Reload.
  3. Click Enable next to the plugin. New plugins always start disabled.

A folder without a valid plugin.json is skipped and doesn't appear in the list.

Installed plugins

Status dotGreen when the plugin is enabled.
Name and versionFrom the plugin's manifest.
SlotWhere its panel docks: right, left, bottom or headless (no panel).
devMarks the plugin loaded through Developer Mode.
Enable / DisableTurns it on or off. Menus update straight away, and disabling closes the plugin's windows.

Developer Mode

Load a plugin straight from your development server, so changes appear as you work.

  1. Tick Enable Developer Mode. A Plugin manifest box appears with a starting manifest.
  2. Edit it: id and entry are required, and entry is your dev server's URL. Set slot to right, left, bottom or headless.
  3. Click Load Plugin. Ink checks the JSON and that the server answers, then confirms “Plugin loaded — switch to font view to see it”.
{ "id": "dev-plugin", "name": "Dev Plugin", "version": "0.0.0", "entry": "http://localhost:5173", "slot": "right", "defaultWidth": 350 }
Invalid JSONFix the manifest's syntax.
"id" and "entry" fields are requiredAdd the missing field.
Cannot reach …Start your dev server, or check the URL.
Server responded with NThe server answered with an error; check the URL.

Untick Developer Mode to unload the dev plugin. Building a plugin is covered in Building plugins.

Trust
  • Every enabled plugin has full access to your fonts, and its Python scripts run with your account's full access. Only install plugins you trust.
  • Developer Mode lets the loaded plugin run scripts from anywhere — enable it only for code you are writing yourself.
